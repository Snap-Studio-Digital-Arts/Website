# Snap Studio & Digital Arts — 3 Page Website

Static website generated from the supplied specification.

## Files
- `index.html` — Home
- `about.html` — About Us
- `services.html` — Services / pricing / quote / FAQ
- `styles.css` — full responsive design system
- `script.js` — animations, theme toggle, mobile menu, counter and quote flow
- `assets/logo.svg` — temporary editable brand-mark placeholder

## Edit points
Search `₹<b>EDIT</b>` in `services.html` to replace prices.
Search `FOUNDER_INSTAGRAM_ID` in `about.html` to replace the founder Instagram.
Replace the SVG in `assets/logo.svg` with the official logo when available.
Replace the four work-card backgrounds/links in `index.html` with real client Instagram URLs.

The quote form currently opens a WhatsApp enquiry with the submitted fields; it does not silently send email because a static front-end cannot securely send email without a backend/email service.
